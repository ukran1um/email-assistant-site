Privacy policy

email-assistant is personal software with exactly one user: its developer and owner. It is not distributed, sold, or made available to anyone else.

What it accesses

With the owner's consent through Google sign-in, it reads messages in the owner's own Gmail account and modifies labels on them (the gmail.modify scope). It never accesses any other person's account.

What it does with the data

Message headers and short excerpts are sent to the Anthropic API solely to decide how to sort each message. Nothing is sold, shared, published, or used for advertising. No mailbox content is stored anywhere except on the owner's own computer, in a local database the owner can delete at any time.

Sending

The program never sends email on the owner's behalf. Reply drafts it prepares are sent only if the owner opens and sends them by hand.

Retention and deletion

Local records are kept on the owner's computer and can be deleted by the owner at any time. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
